CSS Position Demo

1. position: static

STATIC

Static is the default position. top, bottom, left and right do not work.

2. position: relative

RELATIVE

Relative moves the element from its normal position. Space is still reserved for the element.

3. position: absolute

Parent
position: relative
ABSOLUTE

Absolute removes the element from normal flow and positions it relative to the nearest positioned parent.

4. position: sticky

STICKY — Scroll the page ↓

Sticky behaves normally until you scroll to its specified position, then it sticks there.

Scroll down...

The sticky element will remain at the top while scrolling.
