Password Pattern Used
pattern="(?=.*[A-Z])(?=.*[0-9]).{8,}"

This is a regular expression (regex) that enforces password rules.


Full Meaning in Simple Words

The password must:

✅ Contain at least one uppercase letter (A–Z)
✅ Contain at least one digit (0–9)
✅ Be at least 8 characters long

Part-by-Part Explanation

Let’s break it into pieces:

1️⃣ (?=.*[A-Z])

➡ This is a positive lookahead

Meaning:

"Check that there is at least one uppercase letter anywhere in the password"

Breakdown:

?= → lookahead (check condition without consuming characters)

.* → any characters (0 or more)

[A-Z] → one uppercase letter

✔ Examples that satisfy this:

Hello123

Pass9word

A1234567

❌ Invalid:

hello123 (no uppercase)



2️⃣ (?=.*[0-9])

➡ Another positive lookahead

Meaning:

"Check that there is at least one digit"

Breakdown:

[0-9] → any number from 0 to 9

✔ Examples:

Hello1

Abcdef9

❌ Invalid:

Password (no digit)



3️⃣ .{8,}

➡ Controls length

Meaning:

"Allow any character, minimum 8 times"

Breakdown:

. → any character

{8,} → at least 8 characters (no maximum)

✔ Examples:

Abc12345 (8 characters)

StrongPass9 (11 characters)

❌ Invalid:

Ab1c (too short)

How the Browser Uses This
When user submits the form:
Browser checks uppercase condition
Checks digit condition
Checks length condition

If any fail → form will not submit

Shows the message from title attribute



If you want:

✔ uppercase
✔ lowercase
✔ number
✔ special character
✔ 8+ length

Use:

pattern="(?=.*[a-z])(?=.*[A-Z])(?=.*\d)(?=.*[@$!%*?&]).{8,}"
