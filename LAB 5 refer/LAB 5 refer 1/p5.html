HTML Multimedia Embedding Demo

1. Using <embed> Tag (PDF)

The <embed> tag is used to embed external multimedia content like PDFs directly into a webpage.

2. Using <object> Tag (PDF)

The <object> tag provides fallback content if the browser cannot display the file.

3. Using <iframe> Tag (YouTube Video)

The <iframe> tag is used to embed another webpage such as a YouTube video.

4. Using <iframe> Tag (Google Map)

The <iframe> tag can also embed interactive maps from Google Maps.
