CSS Gradients — Every Important Value

Each value is demonstrated separately with its CSS code

1. Linear Gradient — Direction Values

Syntax: linear-gradient(direction, color1, color2)

to right

linear-gradient(to right, red, blue);

to left

linear-gradient(to left, red, blue);

to top

linear-gradient(to top, red, blue);

to bottom

linear-gradient(to bottom, red, blue);

to top left

linear-gradient(to top left, red, blue);

to top right

linear-gradient(to top right, red, blue);

to bottom left

linear-gradient(to bottom left, red, blue);

to bottom right

linear-gradient(to bottom right, red, blue);

2. Linear Gradient — Angle Values

Angles use deg. Common examples are 0°, 45°, 90°, 180° and 270°.

0deg

linear-gradient(0deg, red, blue);

45deg

linear-gradient(45deg, red, blue);

90deg

linear-gradient(90deg, red, blue);

180deg

linear-gradient(180deg, red, blue);

270deg

linear-gradient(270deg, red, blue);

3. Linear Gradient — Color Stops

A color stop tells CSS where a color should appear. Positions can use %, px, etc.

linear-gradient(to right,
    red 0%,
    orange 25%,
    yellow 50%,
    green 75%,
    blue 100%
);

Hard Color Stops

linear-gradient(to right,
    red 0 20%,
    blue 20% 40%,
    green 40% 60%,
    orange 60% 80%,
    purple 80% 100%
);

4. Radial Gradient — Shape Values

Radial gradients support circle and ellipse.

circle

radial-gradient(circle, red, orange, yellow, green);

ellipse

radial-gradient(ellipse, red, orange, yellow, green);

Size Keywords

closest-side

radial-gradient(circle closest-side, red, blue);

farthest-side

radial-gradient(circle farthest-side, red, blue);

closest-corner

radial-gradient(circle closest-corner, red, blue);

farthest-corner

radial-gradient(circle farthest-corner, red, blue);

5. Radial Gradient — Position Values

The at keyword changes the gradient's center.

center

radial-gradient(circle at center, red, blue);

top

radial-gradient(circle at top, red, blue);

bottom

radial-gradient(circle at bottom, red, blue);

left

radial-gradient(circle at left, red, blue);

right

radial-gradient(circle at right, red, blue);

top left

radial-gradient(circle at top left, red, blue);

top right

radial-gradient(circle at top right, red, blue);

bottom left

radial-gradient(circle at bottom left, red, blue);

bottom right

radial-gradient(circle at bottom right, red, blue);

Custom 30% 70%

radial-gradient(circle at 30% 70%, red, blue);

at center

Conic Color Stops

9. Repeating Gradients

Repeating Linear

repeating-linear-gradient(
    45deg, #222 0 15px, white 15px 30px
);

Repeating Linear — horizontal

repeating-linear-gradient(
    to right, red 0 20px, blue 20px 40px
);

Repeating Radial

repeating-radial-gradient(
    circle, red 0 15px, white 15px 30px
);

Repeating Radial — center

repeating-radial-gradient(
    circle at center, blue 0 10px, yellow 10px 20px
);

10. Multiple Gradients

Multiple gradients are separated by commas. The first gradient is painted on top.

background:
linear-gradient(135deg, #ff0066aa, #00ffffaa),
radial-gradient(circle at 70% 30%, yellow, transparent 35%),
#171717;
