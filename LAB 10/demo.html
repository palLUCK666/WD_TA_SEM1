CSS Animation Properties – Complete Demo

1. animation-name

Specifies the name of the animation defined using @keyframes.

none

animation-name: none;

Custom Name

animation-name: nameMove;

2. animation-duration

Specifies how long one complete animation cycle takes.

0s

animation-duration: 0s;

1s – Fast

animation-duration: 1s;

3s – Medium

animation-duration: 3s;

6s – Slow

animation-duration: 6s;

3. animation-delay

Specifies how long the browser waits before starting the animation.

0s

animation-delay: 0s;

2s

animation-delay: 2s;

4s

animation-delay: 4s;

Negative Value

animation-delay: -2s;

4. animation-iteration-count

Specifies the number of times the animation should run.

1

animation-iteration-count: 1;

2

animation-iteration-count: 2;

3

animation-iteration-count: 3;

infinite

animation-iteration-count: infinite;

5. animation-direction

Specifies whether the animation runs forward, backward, or alternates.

normal

animation-direction: normal;

reverse

animation-direction: reverse;

alternate

animation-direction: alternate;

alternate-reverse

animation-direction: alternate-reverse;

6. animation-timing-function

Controls the speed of the animation throughout its duration.

linear

animation-timing-function: linear;

ease

animation-timing-function: ease;

ease-in

animation-timing-function: ease-in;

ease-out

animation-timing-function: ease-out;

ease-in-out

animation-timing-function: ease-in-out;

step-start

animation-timing-function: step-start;

step-end

animation-timing-function: step-end;

steps(5)

animation-timing-function: steps(5);

cubic-bezier()

animation-timing-function: cubic-bezier(0.68,-0.55,0.27,1.55);

7. animation-fill-mode

Specifies what styles are applied before and after the animation.

none

animation-fill-mode: none;

forwards

animation-fill-mode: forwards;

backwards

animation-fill-mode: backwards;

both

animation-fill-mode: both;

8. animation-play-state

Controls whether the animation is running or paused.

running

animation-play-state: running;

paused

animation-play-state: paused;

Hover → paused

.box:hover { animation-play-state: paused; }

9. animation (Shorthand)

Combines multiple animation properties into one declaration.

Normal

animation: shortMove 3s linear infinite;

Reverse

animation: shortMove 3s ease-in-out infinite reverse;

10. @keyframes – Movement Example

The div moves from left → right → bottom → left → top while changing its background color.

@keyframes pathMove { 0% {...} 25% {...} 50% {...} 75% {...} 100% {...} }
